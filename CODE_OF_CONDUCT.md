# Code of Conduct

Este projeto adota um padrão simples de convivência:

- Respeito mútuo em discussões técnicas.
- Críticas ao código, não às pessoas.
- Comunicação clara, objetiva e profissional.
- Zero tolerância para assédio, discriminação ou linguagem ofensiva.

## Escopo
Aplica-se a issues, pull requests, reviews e interações relacionadas ao projeto.

## Reporte de incidente
Reporte comportamentos inadequados por meio de issue privada de segurança conforme `SECURITY.md`.
